# Codex Docs Template

Use this for documentation-only changes.

```text
Goal:
Update documentation for <project/topic>.

Scope:
- Project: <project>
- Repo: <repo>
- Inspect: <docs/files>
- Change only documentation files unless explicitly approved.

Requirements:
- Keep Markdown clear and practical.
- Separate current behavior from future plans.
- Do not claim unsupported integrations exist.
- Include safety boundaries where relevant.

Do not change:
- Do not add dependencies.
- Do not add live API code.
- Do not add secrets or fake credentials.
- Do not edit unrelated product code.

Tests/checks:
- Check file links and headings.
- Check spelling and consistency.
- Confirm required docs exist.

Exit criteria:
- Documentation matches requested scope.
- Future-only behavior is clearly marked.
- Summary lists changed docs.
```
