# Codex Phase Template

Use this for one scoped implementation phase.

```text
Goal:
<one sentence describing the outcome>

Scope:
- Project: <project>
- Repo: <repo>
- Inspect: <files/components>
- Change only: <files/components>

Requirements:
- <requirement 1>
- <requirement 2>
- <requirement 3>

Do not change:
- <constraint 1>
- <constraint 2>
- Do not add secrets, live deployments, or unrelated refactors.

Tests/checks:
- <test/check 1>
- <test/check 2>
- If tests cannot run, explain why and provide manual verification steps.

Exit criteria:
- <observable completion condition 1>
- <observable completion condition 2>
- Summarize changed files and verification results.
```
