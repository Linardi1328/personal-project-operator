# Project Handoff Template

Use this when handing project context to ChatGPT, Codex, or a future operator session.

```text
Project:
<project name>

Purpose:
<one sentence>

Active repo:
<owner/repo or not connected yet>

Current phase:
<phase>

Last approved state:
<known state>

Next action:
<specific next step>

Do not change:
- <constraint 1>
- <constraint 2>

Known risks:
- <risk 1>
- <risk 2>

Suggested Codex task size:
Small / Medium / Large / Too large - split required

Exit criteria for next task:
- <condition 1>
- <condition 2>
```
