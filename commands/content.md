# /content

## Command name

`/content <project>`

## Purpose

Turn project progress into content ideas.

## Input format

```text
/content <project>
```

## Example input

```text
/content portfolio
```

## Expected output

Use for:

- RBL Productions
- portfolio case studies
- LinkedIn project updates
- short-form video ideas

Example:

```text
Content Ideas: Portfolio Website
- Case study: building a phone-controlled project operator.
- LinkedIn post: why read-only-first automation matters.
- Short-form video: turning project chaos into a command menu.
- Safety: draft only, no auto-posting.
```

## Safety boundary

Draft only. Do not auto-post, send messages, publish content, or contact customers.

## Future upgrade path

- Generate channel-specific drafts.
- Link content ideas to project milestones.
- Add approval workflow before publishing.
